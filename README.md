## About

This repository is an index of the projects I have completed in the Common Core at [42 Madrid](https://www.42madrid.com/), grouped by rank, with the grade and a link to the source code of each one.

42 is a peer-to-peer school with no teachers or lectures. Projects are evaluated by other students and by automated tests, and the code must follow a strict coding standard. A grade of 100 means every mandatory part is validated. Grades above 100 include bonus parts. Team projects are marked as *(team)*.
